Professional-grade HTTP server, built in C.

CoreServer demonstrates how a modern web experience can be powered by direct TCP communication, request parsing, MIME handling, and static-file delivery without the overhead of a framework.

01 / OVERVIEW

Built for transparency, speed, and low-level control.

01

Socket foundation

Uses the Berkeley sockets API to open a listening endpoint and accept incoming client connections.

02

HTTP request handling

Parses request lines, identifies supported methods, and returns meaningful status codes and headers.

03

Static asset delivery

Serves HTML, CSS, JavaScript, and other files with correct MIME types to the browser.

02 / ARCHITECTURE

From browser request to response stream.

01 Client Browser issues a request
→
02 Listen socket Accept the TCP connection
→
03 HTTP parser Read method, path and headers
→
04 File handler Resolve the resource safely
→
05 Response Send the HTTP status and payload
This educational implementation keeps the flow simple and easy to audit, making it a strong learning tool for networking fundamentals.

03 / CAPABILITIES

Small in footprint, strong in fundamentals.

01

TCP connection handling

Creates the listening socket, binds it to a port, and accepts each incoming browser connection.

Implemented
02

HTTP method support

Handles GET and HEAD requests while returning clear 405 responses for unsupported methods.

MIME type detection

Implemented
04
